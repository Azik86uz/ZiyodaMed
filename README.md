# Massage Telegram Bot

Этот телеграм-бот позволяет пользователям записаться на массаж через Web-приложение.  
После команды `/start` бот показывает кнопку, ведущую на WebApp.

## Возможности
- Кнопка "Записаться на массаж"
- Интеграция с WebApp (открывается прямо в Telegram)
- Простая настройка
